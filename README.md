# 脚本用法说明

A股短线策略回测与每日信号扫描工具集。Python 环境：`.venv\Scripts\python.exe`。

> **公开仓库说明**
>
> 本仓库为公开代码快照，仅供研究与学习，不构成任何投资建议。历史回测与实证结论均基于特定样本区间，不代表未来收益。
>
> 仓库不包含：全市场行情数据（`stockdb_csv/`、`adata/`）、回测产物与信号表（`output/`）、个人自选股、桌面组件与研究工作台。相关脚本需自行准备数据后运行。
>
> 使用第三方行情数据时，请遵守对应数据源的使用条款。若脚本需要访问数据接口，请通过环境变量提供凭据（如 `TUSHARE_TOKEN`），不要写入代码。

## 目录结构

| 路径 | 说明 |
|---|---|
| `src/` | 核心 Python 脚本（35 个，核心用法见下文章节，其余为研究/实证脚本），命令统一在项目根执行 `python src\xxx.py`；`--strategy` 仍可只写文件名 |
| `stockdb_csv/` | 全市场股票日线数据（**公开仓库未包含**）。本地使用时为 3197 只、2021-08 起、**前复权 qfq**，文件名如 `SH#603002.csv`，数据行 8 列含换手率，是所有分析的默认数据源 |
| `cache_data/` | 股票名、行业、概念等参考数据（`_stock_list.csv`、`_stock_industry.csv`、`_stock_concept.csv` 等），供 scan_signals 行业标注与情绪/题材脚本读取；不复权行情 CSV 不在仓库中，`--cache`/`--dir cache_data` 仅在自行下载后用于对账 |
| `idx_data/` | 大盘指数日线（沪深300 `000300.SH` 等，择时用） |
| `output/` | 运行结果输出目录（仓库中不包含历史产物）：`signals_YYYYMMDD.xlsx`、`backtest_result_*.png/html` |

## 1. scan_signals.py — 每日全市场信号扫描（最常用）

扫描全部股票，输出当天（或指定交易日）的买入/卖出信号，结果存 Excel。

```
.venv\Scripts\python.exe src\scan_signals.py                       # 扫描最新交易日（默认 strategy_normal）
.venv\Scripts\python.exe src\scan_signals.py --date 2026-09-10     # 指定历史日期
.venv\Scripts\python.exe src\scan_signals.py --timing               # 开启大盘择时（默认关闭）
.venv\Scripts\python.exe src\scan_signals.py --sort return         # 按回测收益排序（默认按信号）
```

输出：`output/signals_YYYYMMDD.xlsx`（按日期命名存档，含"买入信号""卖出信号"两个 sheet，每行附该票 2026 年回测收益/**回测夏普**/胜率/交易数、信号日**量比**与**成交额(亿)**）。文件被 Excel 占用时自动改写 `_new.xlsx`。量比＝信号日成交量/前20日均量，成交额＝成交量×当日收盘价（亿元），乖离%＝(收盘−MA20)/MA20；**20日波动率%**＝近20个日收益样本std(ddof=1)×√252 年化（口径同 risk_metrics.py），**波动率分位**＝该值在个股自身历史（截至信号日，2021-08 起全样本，滚动样本≥60 才输出）20日滚动波动率序列中的百分位（0=近5年最低、100=最高，平均秩处理并列）；**个股夏普**＝信号日前近250个交易日买入持有该股的年化夏普（与策略无关，不足60日留空）；**回测夏普**＝2026回测窗口（含2025-11预热段）每日盯市净值算的策略年化夏普（口径同 risk_metrics.py，rf 默认 1.5%，`--rf` 可调；main 模式不跑回测、该列留空）。以上均仅展示不参与信号，用于信号扎堆时按"成交额≥0.5亿、量比最小"择优（5年实证口径，见 `.trae/skills/risk-rule-backtest/SKILL.md` 横截面择优条目），波动率/夏普列用于并列观察信号票当前风险水平在自身历史中的位置与策略风险调整后收益。

**环境雷达（汇总 sheet + 控制台，main/normal 均有）**：每日统计 HS300 在 MA20 线上/线下、全市场乖离<−10%/<−15% 个股数。**亮灯条件：指数线上且 <−15% 个股数 ≥300**——5 年逐日校准仅 2024-02-06/07/08/19/20 五天触发（当月深乖离抄底均 +12%/胜率 98%），零误报；平时静默，只在"指数还撑着、个股已极端超跌"的崩盘 V 反窗口亮灯。亮灯时 Excel 自动生成「V反雷达候选」sheet（当日买入信号中乖离<−10% 且成交额≥0.5亿）。注意：雷达不改变任何买卖逻辑，熊市指数线下的超跌不亮灯（5 年中线上门控有 3 年负贡献，不做"线下禁止抄底"）。

**扫描 main.py 三信号策略的当日信号**（`--strategy main`）：numpy 状态机逐日精确复刻 main.py 的 backtrader 撮合——买入三信号 A 回踩/B 上穿/C 影线（同优先级），影线持仓的低开1%/止损5%开盘卖、盘中触价5%止盈、3倍大阴线、收盘止损、双涨停顺延，上穿持仓的 T+1 高开开盘卖/收盘包孕等待 T+2，回踩 T+1 收盘卖，以及 HS300 MA20 破位离场；参数常量直接 exec main.py 取得——main 改参数扫描自动跟随。**默认扫 `stockdb_csv`（前复权，3197 只，更新到最新交易日）**，状态机从 main 的回测起点 2024-09-09 起模拟持仓，因此"卖出信号"即当前持仓当日应卖清单；加 `--dir cache_data` 可回到 main.py 的 tushare 不复权口径（621 只，逐笔对账基准）。输出 `output/signals_main_YYYYMMDD.xlsx`（无回测相关列，回测夏普留空；含量比/成交额/20日波动率%/波动率分位/个股夏普/乖离列与环境雷达，卖出信号排在控制台前面）。

```
.venv\Scripts\python.exe src\scan_signals.py --strategy main                 # 三信号策略·最新交易日
.venv\Scripts\python.exe src\scan_signals.py --strategy main --date 2026-08-19
.venv\Scripts\python.exe src\scan_signals.py --strategy main --timing        # 开启择时（同 main.py --timing）
```

买入信号：`回踩`/`上穿`/`影线`。卖出信号类型：`大盘破位`/`大盘破位开盘补离`/`低开开盘卖`/`开盘止损卖`/`盘中触价止盈`/`大阴线卖`/`收盘止损卖`/`涨停顺延结束收盘卖`/`上穿高开开盘卖`/`上穿T+1收盘卖`/`上穿T+2开盘卖`/`上穿T+2收盘卖`/`回踩T+1收盘卖`；`破位涨停·顺延次日开盘`、`止盈触发·涨停顺延` 表示当日触发卖出但封板未成交、进入顺延。该状态机已与 main.py backtrader 逐笔对账（2026-09-16，cache_data 621 只有效票：择时关闭 23906 笔、exit 档 15030 笔，日期/方向/价格零偏差）。

## 2. strategy_normal.py — 单票回测 + K线图（跳空放量策略）

backtrader 逐日撮合，控制台打印明细表，生成 PNG + 交互 HTML 图表。

```
.venv\Scripts\python.exe src\strategy_normal.py 603002             # 支持多种写法：603002 / 603002.SH / SH#603002
.venv\Scripts\python.exe src\strategy_normal.py 000017.SZ
```

数据查找顺序：`stockdb_csv/`（前复权首选）→ 项目根目录 → `cache_data/`。输出：`output/backtest_result_{代码}.png/.html`。

大盘择时**默认关闭**（2026-09-16 起），完全按个股 MA5 买卖信号跑；需要时加 `--timing` 开启（HS300 MA20 exit + 涨停顺延，仅当次运行生效）：

```
.venv\Scripts\python.exe src\strategy_normal.py 603002 --timing
# 或环境变量（PowerShell）
$env:MARKET_TIMING='000300.SH:20:exit'; .venv\Scripts\python.exe src\strategy_normal.py 603002
# cmd
set MARKET_TIMING=000300.SH:20:exit&& .venv\Scripts\python.exe src\strategy_normal.py 603002
```

开启后指数跌破 MA20 时拦截新仓、持仓当日收盘强制破位离场（exit 模式）。旧参数 `--no-timing` 仍兼容（显式关闭，可覆盖环境变量）。

## 3. main.py — 单票回测 + K线图（三信号策略：回踩/上穿/影线）

三信号买入（A 回踩 MA20、B 上穿 MA20、C 长下影十字星），影线持仓含低开/止损/止盈/大阴线卖出与涨停顺延，上穿持仓走 T+1 包孕等待、回踩 T+1 收盘卖；用法与 2 相同：

```
.venv\Scripts\python.exe src\main.py 000017.SZ
.venv\Scripts\python.exe src\main.py 000017.SZ --timing       # 开启大盘择时（默认关闭）
.venv\Scripts\python.exe src\main.py --timing                 # 不带代码=默认 000017.SZ
```

数据查找顺序同 strategy_normal：`stockdb_csv/SH#代码.csv`（前复权首选）→ 项目根目录 → `cache_data/代码.csv`，支持 603002 / 603002.SH / SH#603002 三种代码写法。

对多只/全部股票跑 backtrader 回测并汇总排名。

```

.venv\Scripts\python.exe src\batch_test.py --profit-only --sort win_rate   # 只看盈利票、按胜率排

```

## 7. risk_metrics.py — 风险指标（夏普/Sortino/波动率/回撤）

基于每日收盘账户净值（持仓按收盘价盯市）计算风险调整后收益指标，默认扫 `stockdb_csv` 前复权全市场，与回测引擎同一撮合链路。

口径（输出前打印声明）：日简单收益 `NAV_t/NAV_{t-1}−1`；年化基准 252 交易日；年化波动＝样本标准差(ddof=1)×√252；夏普＝(日均收益−rf/252)/日std×√252；Sortino 分母为低于 rf 的目标半偏差（ddof=0）；无风险利率默认 1.5%（`--rf` 单一来源可调）；全程空仓 std=0 时夏普/Sortino 记 N/A。

```
.venv\Scripts\python.exe src\risk_metrics.py 600487.SH --strategy strategy_normal.py  # 单票+分年拆解
.venv\Scripts\python.exe src\risk_metrics.py                                          # 全市场（默认 main.py）
.venv\Scripts\python.exe src\risk_metrics.py --strategy strategy_normal.py --timing   # normal 策略+择时对照
.venv\Scripts\python.exe src\risk_metrics.py --rf 0.02 --sort sortino                 # 改无风险利率/排序
```

单票输出总收益/CAGR/年化波动/下行波动/夏普/Sortino/最大回撤/卡玛/持仓日占比 + 分年表；多票输出排名表、个股分布与等权组合指标（日收益横截面等权再累计）。**跨策略比较夏普必须同时看持仓日占比**：影线策略长期接近空仓（组合年化波动仅 1.6% 但收益≈0），低波动不代表低风险高收益。

## 8. market_timing.py — 大盘择时配置（被各脚本引用，不单独运行）

**2026-09-16 起择时默认关闭**：所有脚本不带参数即纯个股信号口径。需要时加 `--timing` 开启（exit 模式：沪深300 收盘跌破 MA20 时不开新仓，已持仓的当日收盘离场）。
全市场实证（3193 只，2025-11~2026-09，引擎原生信号）：组合收益 +0.4%→+3.2%，回撤 −9.1%→−5.1%。

exit 模式附带**涨停顺延（B版，全市场实证 +0.3pct、回撤 −0.1pct）**：破位当日个股收盘封涨停则不卖；之后每个交易日开盘检查，开盘未封涨停即以开盘价卖出，继续封板继续持有；指数先站回 MA20 则取消离场。ST 按 5%、创业板/科创板按 20%、北交所按 30% 识别涨停。

开启择时的快捷方式：`main.py`、`strategy_normal.py`、`batch_test.py`、`backtest_stockdb.py`、`risk_metrics.py` 均支持 `--timing` 命令行参数（仅本次运行生效）；`scan_signals.py` 的 `--timing` 还可带值选模式。旧参数 `--no-timing` 隐藏保留，用于在环境变量开启时显式覆盖关闭。

三种改参方式：

```
# 命令行（推荐，仅本次运行生效）
.venv\Scripts\python.exe src\main.py 000017.SZ --timing

# 环境变量（对任何脚本生效；PowerShell 用 $env:MARKET_TIMING='...'）
set MARKET_TIMING=off                    # 显式关闭（覆盖库默认之外的任何开启意图）
set MARKET_TIMING=000300.SH:20:exit      # 破位离场（--timing 的等价配置）
set MARKET_TIMING=000300.SH:20:gate      # 只挡新仓，不强制离场
set MARKET_TIMING=000300.SH:20:half      # 线下半仓
set MARKET_TIMING=000300.SH:20:exit:nolu # 关闭涨停顺延，破位当日无条件收盘离场

# scan_signals 专用参数（--timing 不带值=exit）
.venv\Scripts\python.exe src\scan_signals.py --timing gate --timing-ma 15
.venv\Scripts\python.exe src\scan_signals.py --timing --no-lu-exempt    # 关闭涨停顺延

# 代码里调用
import market_timing as mt; mt.configure(mode='exit')
```

## 9. 择时规则实证结论（2026-09，3193 只全市场）

**为什么是"破位即走"而不是"等个股跌破 MA5 再卖"**——三态对照：

| 规则 | 组合收益 | 组合回撤 | 个股中位 | 胜率 |
|---|---:|---:|---:|---:|
| 不择时 | +0.41% | −9.06% | −10.16% | 30.0% |
| gate（线下挡新仓，卖出等个股破 MA5） | +1.07% | −6.16% | −7.33% | 30.2% |
| **exit+B（`--timing` 口径：破位即走，涨停顺延）** | **+3.15%** | **−5.05%** | **−4.18%** | 34.3% |

9430 笔破位离场逐笔配对：破位即走单笔均 +4.23%/胜率 78%，等 MA5 卖 +3.14%/54%；等待期中位多亏 1.71pct，仅 23% 的票等一等更好，最差 −52%、最好 +125%。强制离场贡献了择时增益的大头（约 2pct），MA5 在系统性下跌段确认太慢。

**"大盘下跌时抗跌的强势股"每轮都有，但身份不固定、无法事前识别**（2024 年以来 16 轮 HS300<MA20 波段跨期检验）：

- 相邻波段个股相对强度秩相关均值仅 **+0.05**，正负号反复；上轮最强 20% 下轮仍在最强 20% 的比例 12%~35%，随机基准就是 20%；
- 同一只票多次破位时"等 MA5 更优"命中率 0.22，与总体基准 0.23 无异，"反复强势股"只占 6.0%（随机也有 5.3%）；
- 破位日事前可得特征（前20日涨幅、距 MA20、量比）与等待收益全部**负相关**（−0.15~−0.17，前期越热越补跌），仅连板数微正（+0.03）；样本外按动量前 10%/20%/30%/50% 豁免，混合收益全部低于破位即走；
- 真正决定强势股占比的是下跌性质（深跌段仅 5%~14% 上涨、浅调段 56%~71%），而下跌深度在破位当天不可预知。

**因此规则定为：破位即走（对 77% 的情形正确），唯一例外是破位当日收盘封涨停（最强连板票，事前可客观判定），由 B 版涨停顺延豁免，次日开盘不封板立即走。** 不做动量/强势度主观豁免。样本局限：2024-01~2026-09、单一市场环境，参数需跨周期复核。

## 10. 数据下载与更新

## 11. sentiment_snapshot.py / sentiment_rules.py — 情绪快照与规则判定层

由全市场日线合成每日短线情绪指标序列，再把固定情绪规则翻译成当日行动结论。

**sentiment_snapshot.py**（快照，每天收盘跑一次）：

```
.venv\Scripts\python.exe src\sentiment_snapshot.py                        # 默认 stockdb_csv, 2026 全年
.venv\Scripts\python.exe src\sentiment_snapshot.py --dir stockdb_csv --start 2025-10-01
.venv\Scripts\python.exe src\sentiment_snapshot.py --update-index         # 先经 baostock 更新沪深300 再算
```

输出 `output/sentiment_daily.csv`（每日一行）：涨停/炸板/封板率/昨涨停溢价/晋级率/最高板/连板家数/跌停/一字板/缩量板/top1题材/温度分/阶段/高标分歧/HS300+MA20/温度分位 temp_pct。口径：剔 ST 与退市整理股、上市前 5 日不计，涨停阈值沿用 first_board_premium（9.8/19.8/4.8 容差）；温度分 = 宽度 22% + 封板率 16% + 溢价 26% + 晋级率 16% + 高度 20% − 跌停惩罚（映射分位与权重均为文件顶部常量，可调）；阶段：溢价≤−1.5% → 退潮（最高优先级），否则按温度分 30/45/70 划冰点/修复/发酵/高潮。**高标分歧（最高板≥4 且封板率<62%）不再覆盖阶段**，改为并列字段 `diverge`：旧口径曾把它当阶段，吞掉约 111 天冰点/修复、且温度 3~86 分都叫分歧，压缩了“冰点/修复→转强第一天”的窗口。另有参考列 `temp_pct`：当日温度在最近 120 个交易日（含当日，至少 60 日历史）中的百分位（0=最冷、100=最热，并列取低于数占比），用于判断当前温度相对近半年偏冷还是偏热（如 2026-10-30 温度 17 → `temp_pct` 6.7）；**仅供观察，不参与阶段/门控/仓位任何判定**。滚动分位阈值（过去 120 日 20/50/80 分位）已做过双窗口对照：分布更均衡（13/39/27/18），但门控置换 p 由 0.014 退化到 0.085、各阶段次日溢价仍非单调，且牛市中 q20 会升到 44 分（44 分被叫“冰点”语义失真），故阶段边界继续用绝对刻度 30/45/70。

**阶段平滑（2026-11）**：滞回 4 分（跨档需越过边界 4 分）+ 最短持有 3 日 + 暴跌硬阀（温度≤20 立即判冰点、极端档跨两档立即改判、退潮按溢价立即生效）。585 天切换由 379 次降至 200 次（每 2.9 天一次）；修复/发酵/高潮的中位连续段均为 3 天，冰点/退潮保持 1 天以便风控快速响应。剩余已知问题：30/45/70 实际对应分位 13%/33%/77%，四档样本仍不均（冰点 8.7% / 修复 24.1% / 发酵 42.7% / 高潮 20.7%）；滚动分位口径已做对照验证，结论是只增 `temp_pct` 参考列、不切换阶段阈值。

同时输出 `output/sentiment_industry.csv`（行业×交易日，按 CSRC 行业）：`zt_n` 当日涨停家数、`zt_prev` 昨日涨停家数、`prem_avg` 昨日涨停股今日平均溢价、`pos_ratio` 溢价覆盖率（上涨占比）、`dt_next` 昨涨今跌停家数、`promo_ratio` 晋级率、`max_board` 当日该行业最高板，以及 `first_board_n` 当日首板家数和最高标字段 `leader_name`/`leader_board`（昨日该行业最高板，≥3 板才记）、`leader_break`（今日未封板）、`leader_dt`（今日跌停）。用途是板块级退潮信号：某行业昨日涨停≥3 家时，覆盖率<50%、或跌停≥2 家、或有 1 家跌停且覆盖率<60%、或最高标跌停 → 该板块不接力；最高标断板且当日首板为 0 家 → 题材结束（阈值见文件顶部 SECTOR_* 常量）。

同时输出 `output/sentiment_concept.csv`（概念×交易日，字段与行业级完全一致，主键列名为 `concept`），数据来自 `cache_data/_stock_concept.csv`（同花顺概念成分，股票覆盖 99.7%）。**为什么要概念口径**：机器人、算力这类题材横跨多个 CSRC 行业（机器人 = C34 通用设备 + I65 软件），行业级指标切不开题材，会出现"行业健康但题材已崩"的误判——2026-10-29 C34 显示"健康(未退潮)+15"，而同日的机器人概念从昨 26 家缩到今 7 家、覆盖率 27%，实际是退潮预警。聚合前会剔除资金/风格类伪概念（融资融券、深股通、富时罗素、专精特新、预增等，名单见文件顶部 CONCEPT_JUNK / CONCEPT_BLACKLIST）。**个股板块判定口径 = 行业 ∪ 所属活跃题材（今或昨涨停≥3 家）取较差者**，行业健康不算数。

**sentiment_rules.py**（规则判定层，读取快照 + 当日明细）：

```
.venv\Scripts\python.exe src\sentiment_rules.py                     # 最新交易日结论
.venv\Scripts\python.exe src\sentiment_rules.py --date 2026-10-16   # 历史回看(需快照已覆盖)
```

输出当日结论与适用规则清单：宽度×高度（有宽度没高度低吸/有高度没宽度打板）、大盘杀跌找抱团/上涨找共振（HS300 对 MA20 × 题材集中度）、资金合力（top3 分散 + 昨涨停溢价<1% → 无合力，降仓/空仓）、主线转弱禁支线禁缩量板/主线转强闭眼买前排（冰点/退潮/无合力时只算“转强苗头”，等确认）、情绪转弱第一天禁一切盘中板/转强第一天抢辨识度（退潮期温度反弹不算转强）、加速票一概不接（连板≥3 且一字/缩量）、4 板以上高位段（唯一最高标只可低吸、其余一律不接）、5 板+ 龙头梯队与断板观察、超预期观察创业板弹性、阶段→仓位档 + 单票上限（5 成，高位票 3 成，禁满仓单票隔夜）、炸板/溢价/跌停异动反馈。规则阈值均为文件顶部常量（BREADTH_HI/HEIGHT_HI/MAIN_N/SINGLE_POS_CAP 等），改完重跑即生效。

另有几段来自实战复盘的判据：

- `[板块分层]`：按当日涨停家数取前 3 个行业，拆成龙头（最高板）/ 连板（2 板以上）/ 补涨（首板，按开盘涨幅排序）。打板只打龙头，补涨只做最先封板的那只；全是首板时标“无梯队”。
- `[板块温度]`：取当日涨停最多的前 5 个行业，给出昨涨停股今日溢价/覆盖率/跌停/首板家数；昨日涨停≥3 家时，最高标断板且首板为 0 → “题材结束”（全行业扫描，当日禁做该板块），覆盖率<50%/跌停≥2/最高标跌停 → “退潮预警”，覆盖率≥50% → “未退潮（仍可接力）”。
- `[题材温度]`：同口径的概念版，取昨日涨停梯队最大的 6 个题材。行业健康但题材退潮时以题材为准（个股板块判定 = 行业 ∪ 所属活跃题材取较差者），并在该段末尾提示该口径。
- `[兑现纪律]`：统计昨日涨停股今日冲高（最高≥+5%）后回落≥5pct 的名单，以及昨日 4 板以上今日未封的高位断板，对应“冲高不卖/炸板不走/高位断板不接”的执行教训。
- `[分歧日新题材首板]`：仅在高标分歧（`diverge=1`，最高板≥4 且封板率<62%）或退潮时扫描“昨日 0 家涨停、今日 2 家+ 且全为 1 板、且该行业近 60 个交易日无单日 ≥5 家涨停（近期未高潮）”的全新题材，列出首板名单（只做梯队里最先封板的辨识度）。仅“昨 0 家”不够：刚炒过一轮、只歇一天的旧题材也会满足，必须叠加“近期未高潮”。

未覆盖项：竞价量比（1/20~1/10 阈值）需要集合竞价成交量，日线数据只有全天量，当前脚本无法计算，`[板块分层]` 暂用当日开盘涨幅近似；接入分钟线/竞价数据源后再补。

## 12. zt_rank.py — 涨停候选打分排序（v3 实测刻度口径）

对当日涨停候选做横截面排序，输出可买池与 Top 名单。**v1 原打分的惩罚项符号是反的**（4/5 板、缩量板次日实测更强），v2 已删除全部惩罚，只保留实测有正向区分度的四项，刻度来自可买子集分箱统计（每日等权，2024-07~2026-10）。**v3（默认）**按分箱单调性收紧板数/缩量/低开三处刻度，并加“题材高连板全断”退潮过滤——刻度收紧主要为风控语义（不奖励追高、缩量低开不抬分），收益上样本内 +0.02pp、样本外 −0.10pp。

```
.venv\Scripts\python.exe src\zt_rank.py                     # 最新交易日
.venv\Scripts\python.exe src\zt_rank.py --date 2026-10-29
.venv\Scripts\python.exe src\zt_rank.py --top 10 --all      # 详细列出全部入选（剔除票始终列出）
.venv\Scripts\python.exe src\zt_rank.py --no-dv-switch      # 关闭分歧日切换池
```

**候选池与剔除**：当日收盘涨停（阈值同 sentiment_snapshot：9.8/19.8/4.8/29.8）。**买不进不再剔除**：非一字且开盘 <9.5% 记 `buyable=可买`，一字/开盘≥9.5% 记 `买不进`，仍照常打分并出现在控制台与 CSV，由使用者自行判断（原口径直接剔除会把 64 分的上海沪工这类强势票藏起来）。**退潮只按最强题材剔除**：候选取行业 + 所属活跃题材（今或昨涨停≥3 家）中强度（`theme_strength`）最高者，只有它退潮/结束才整票剔除（判定见 `sector_ok`：龙头断板且首板 0 = 题材结束，跌停/覆盖率不达标 = 退潮，龙头断板本身不算退潮）；同等强度优先取健康题材，其余退潮题材只写入 `weak_themes` 警告。

原因：原口径“任一活跃题材差即剔除”会被静态/边缘概念标签误杀——澳洋健康（002172，10-30 3 板）真实驱动是养老概念（5 家/昨 1、覆盖率 100%、最高 3 板，健康），但概念表里的冷链物流（3/昨 5、覆盖率 20%、2 家跌停、龙头断板+跌停）与三胎概念（4/4、覆盖率 50%、dt=1）退潮，整票被剔除。实证（内 240 天 / 外 325 天，可买候选）：被原口径误杀而最强题材健康的 4622/4644 只，次日 **+1.19%/+1.42%**（胜率 54%/55%），接近健康组 +1.36%/+2.27%，明显高于真正该剔除的“最强题材也差”组 +0.73%/+1.28%（51%/54%）。

**概念黑名单**：本轮新增 26 个非题材/宽泛标签（黑名单累计 47 个），分两类——(1) 持仓/牌照类 13 个（`参股银行`、`参股券商`、`参股保险`、`信托概念`、`国家大基金持股`、`村镇银行`、`金控平台`、`互联网保险`、`互联网券商`、`参股外资金融`、`T+0基金`、`基金三方销售`、`科技保险`，连同原有的 `证金持股`/`基金重仓`）：它们常因 5 家以上涨停给出 18 分板块强度，但涨停只是持仓巧合而非题材驱动；(2) 宽泛政策/生态类 13 个（`碳中和`、`工业互联网`、`AI智能体`、`无人机`、`智能医疗`、`智能电网`、`数据要素`、`虚拟现实`、`网红经济`、`统一大市场`、`雄安新区`、`抖音概念`、`特斯拉概念`）：作为“最强题材”时内/外双窗口均跑输可买基准。双窗口可买 Top5 对照：内 **+2.03%→+2.07%/日**（18/240 天换票）、外 **+2.37%→+2.39%/日**（27/324 天换票）、最近一月（2026-10）累计 **+28.19% 不变**（0 换票）。`文化传媒概念`、`腾讯概念`、`AI应用` 三个标签虽双窗口同样跑输，但整批加入会让最近一月 5 个换票日全部变差（累计 +28.19%→+19.49%），按“变差就回退”暂留观察。`T+0基金` 等含 `+` 的标签在 `str.contains` 里已用 `re.escape` 转义，避免正则量词误配。

**四项打分**（满分 76，无惩罚项）：

| 项 | 刻度 | 实测依据 |
|---|---|---|
| 题材强度 0~30 | 最强题材今涨停 <3/3-4/5-7/8+ → 0/10/18/25；该题材最高板 3/4/5+ 再 +2/+3/+5 | 板块今涨停 IC +0.054(t=4.93)，8+ 组 +1.44% vs <3 组 +0.84% |
| 板数 0~16 | 1/2/3/4/5/6+ → 0/10/14/14/16/10 | 内 1→3 板 +1.29/+1.71/+2.20%，4 板回落 +1.02%、6 板 +0.97%；外 3/4/5 板 +2.76/+2.91/+2.55%、6 板 +0.59% |
| 开盘涨幅 0~20 | <-3/-3~0/0~3/3~6/6~9.5% → 6/0/2/5/20 | <-3% 档实测 +1.33%，低于 -3~0 的 +1.44%（原给 12 分偏高）；6~9.5% 组最强 |

**阶段门控**：仅 修复 / 发酵 / 高潮 三个阶段启用横截面排序；冰点 / 退潮只出名单并在控制台提示“门控关闭”（打板只在转强第一时间窗口）。`sentiment_rules.py` 的 `[打板排序]` 段同步输出当日是否启用。门控实际只剔除冰点/退潮（约占一成天数），样本内 187/198 天、样本外 247/259 天启用，**门控增益 +0.13pp（置换 p=0.030）/ +0.08pp（p=0.070，样本外不显著）**——它只是“极冷日不做”的纪律，不是收益来源。

**双窗口验证**（可买池 + 剔除退潮，Top5−Bottom5 次日收益差；相邻两窗口不重叠）：

| 口径 | 样本内 2025-11~2026-10（198 天） | 样本外 2024-07~2025-10（259 天） |
|---|---|---|
| v2 刻度 | Top5 +1.67% / 差 +1.22pp / 胜率 63% | +2.32% / +0.87pp / 61% |
| v3 刻度 | +1.72% / +1.24pp | +2.25% / +0.78pp |
| v3 刻度 + 全断过滤（默认运行） | +1.69% / +1.18pp | +2.15% / +0.69pp |
| 再加阶段门控（v2 刻度实测） | 187 天 +1.35pp / 64% | 247 天 +0.94pp / 62% |
| v1 原口径对照 | 差 −0.84pp / 43% | −1.20pp / 35% |

v3 三处收紧的代价：样本内 +0.02pp、样本外 −0.10pp；单改分解（内/外）板数 +0.05/−0.02pp、缩量条件化 +0.02/−0.07pp、低开 12→6 0/−0.07pp——样本外都是小幅负贡献，换来的是“4 板以上不再抬分、缩量低开只给一半、低开<-3 不再高配”的风控语义。再叠加全断过滤让出约 0.06pp（内）/0.09pp（外）。500 次日内打乱分数-收益配对的置换检验显示，v3 刻度与 v3+过滤在两窗口的差值 p 均 ≤0.004（排序区分度非偶然）。

门控阶段最初是在看过两个窗口的阶段表后才选定，本身带选择偏差；2026-11 的置换检验印证了这点：样本内增益 +0.13pp（p=0.030），样本外仅 **+0.08pp（p=0.070，不显著）**，即门控基本不提供收益。保留它只因为符合“冰点/退潮不做打板”的纪律，且空仓日的差值本就不含优势，代价仅是少做。

**v3 过滤（默认开启，`--no-v3` 关闭）**：在 v3 刻度上追加“题材高连板全断”退潮确认——候选最强题材里昨日连板≥3 的股票今日全部未封板 → 剔除。该组候选次日 +0.72%（内）/+1.66%（外），全封组 +1.53%/+1.79%。叠加过滤后 Top5：内 +1.72%→+1.69%、差 +1.24→+1.18pp，外 +2.25%→+2.15%、差 +0.78→+0.69pp（内 468 只 / 外 394 只被剔除），属“用约 0.06pp（内）/0.09pp（外）收益换取高标全断日不接力”的风险偏好。2026-10-28 实跑剔除 10 只，10-29 无昨日高标可断、剔除 0 只。

**分歧日切换池（默认开启，`--no-dv-switch` 关闭）**：`diverge=1`（最高板≥4 且封板率<62%）且阶段门控开启（修复/发酵/高潮）时，若入选候选里存在**行业级新题材首板**，只在其中按现有分数排序，其余入选票转“观察·分歧日切新题材”（买不进票不参与切池，避免挤掉可买票）。新题材口径为：昨日该行业 0 家涨停、今日≥2 家且全为 1 板，**且近 60 个交易日该行业无单日 ≥5 家涨停（近期未高潮）**——只查“昨 0 家”会把刚炒过、只歇一天的旧题材误判成新题材（如 2026-10-28 的 C39 前 60 日曾单日 20+ 家涨停）。实测（行业口径，与 `sentiment_rules` 的 `[分歧日新题材首板]` 同定义）：

| 窗口 | 门控开启分歧日 | 原 Top5 | 切换后 |
|---|---:|---:|---:|
| 内 2025-11~2026-10 | 36 天（触发 11 天） | +1.09% | **+1.57%** |
| 外 2024-07~2025-10 | 73 天（触发 26 天） | +1.87% | **+2.23%** |

全窗口（仅门控分歧日切换）Top5 为 +1.56%→+1.63%（内）、+2.10%→+2.18%（外）。新题材组在分歧日：内 40 只/13 天 **+2.35%**（胜率 72%、日等权 +1.77%）、外 86 只/33 天 **+3.52%**（67%、日等权 +3.31%），均优于仅“昨 0 家”的旧口径（内 91 只 +2.12%、外 191 只 +2.03%）。参数来源：回看 60 日、阈值 5 家时两窗口同时优于旧口径；阈值提高到 6 家后门控分歧日增益缩小到 +0.11/+0.30pp，阈值 8 家样本内转负；全历史“从未高潮”过于严格（内样本仅 2 天、外 7 天），规则几乎不触发。切换池增益的配对 t 仅 1.04/1.23（触发日少、样本弱），依据是两窗口同向 + 个股组质量提升，而非单日胜负。

2026-10-28 用新口径不再触发切池（C39/C26 近 60 日均已高潮），维持原排序 Top5 +5.43%；旧口径会切到 2 只新题材（次日 −1.85%）。另外**直接给新题材加分效果更差**（内分歧日 Top5 0.68%→0.54%），所以用切池而不是加分。

输出 `output/zt_rank_YYYYMMDD.csv`：全部候选一行，含 `rank/score/sec_sc/board_sc/gap_sc/suoliang_sc/theme/theme_zt_n/theme_max_board/status/buyable/weak_themes/next_ret`。`status` 区分「入选 / 剔除·题材退潮/结束 / 剔除·题材高连板全断(v3 默认) / 观察·分歧日切新题材」；`buyable` 区分「可买 / 买不进」（买不进照常入选展示，次日验证单列参考，其收益按收盘算、实际不可成交）。控制台固定列出「入选 Top N」与「全部剔除票」（**高分买不进票即使因题材退潮被剔除也会出现在剔除区，可直接判断**），`--all` 详细列出全部入选；控制台 `#` 是入选名单序号（1..N），CSV 的 `rank` 是全表排名（被剔除票也占位）。

## 常见问题

- **报错但像跑完了**：Windows 下部分 stderr 输出是库的误报，以实际输出为准。
- **Excel 写不进去**：关掉打开的旧文件重跑即可，程序会自动落 `_new.xlsx`。
- **零信号**：择时默认关闭；若加了 `--timing` 或设了 `MARKET_TIMING` 环境变量，指数在 MA20 下方时买入被拦截是正常行为，去掉参数（或 `--no-timing`）即可对照原始信号。
- **回测口径**：成本含双边佣金 0.05%（最低5元）+ 卖出印花税 0.05%；买入按信号日收盘价、卖出按收盘跌破 MA5 的当日收盘价；2026 年全年窗口（含 2025-11 起的预热段）。
