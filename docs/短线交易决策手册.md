# 短线交易决策手册

> 整理自个人交易规则体系：环境判断 → 战法选择 → 个股条件 → 仓位止损。
> 仅作个人复盘查阅，不构成投资建议。

---

## 一、总纲：环境决定战法

| 原则 | 说明 |
|---|---|
| 仓位管理才是成功的法门 | 任何战法的前提都是活着，仓位是第一约束 |
| 空仓 ≠ 害怕 | 空仓是因为没有合格标的（选美式空仓），不是因为情绪 |
| 环境 > 战法 | 环境不对，动作再熟也是亏；环境对了，动作还要对才能赚 |
| 持续跟踪反馈 | 密切关注异动品种反馈、即将异动品种反馈 |

**一句话主线**：先判环境 → 定战法 → 验条件 → 最后才是仓位与止损。

---

## 二、环境识别（宽度 / 高度四象限）

| 市场状态 | 战法 |
|---|---|
| 有宽度 · 没高度 | **低吸** |
| 有高度 · 没宽度 | **打板** |
| 大盘杀跌 | **找抱团** |
| 大盘上涨 | **找共振板块龙头 → 打板** |

> 宽度 = 涨停家数、赚钱效应覆盖的广度；高度 = 最高连板数、梯队完整度。

---

## 三、情绪周期节点（做与不做）

### 3.1 该做的

| 节点 | 动作 |
|---|---|
| 冰点修复转强 | 低吸 |
| 加速分歧 | 打板 |
| 行情只做「转强」和「修复」 | 趋势行情只做「分歧」和「延续分歧」 |
| 情绪转强第一天 | 抢第一时间窗口的辨识度 |
| 主线转强节点 | 闭眼买前排核心辨识度（超预期） |

### 3.2 绝对不做的

| 节点 | 禁令 |
|---|---|
| 情绪转弱第一天 | 杜绝一切盘中任何涨停板 |
| 主线转弱节点 | 不要碰支线任何缩量板 |
| 任何加速票 | 一概不接 |
| 主板跟风票 | 不看，改看创业板弹性 |

## 四、龙头首阴战法（断板反包）

### 4.1 核心前提

**只有绝对核心龙头配叫「首阴」。** 杂毛股、跟风小弟断板叫原形毕露，没人会去救它。
必须是全市场最高标、板块的绝对灵魂、所有人都盯着的总龙头——因为只有它有人气基础，断板后才有资金尝试反包。

### 4.2 六条检查（C1–C6）

| 编号 | 检查项 | 规则原文要点 | 量化判定 |
|---|---|---|---|
| **C1** | 江湖地位 | 必须是绝对核心龙头，全市场最高标 | 断板前连板数 ≥ 5，且与当日市场最高板差距 ≤ 1 板 |
| **C2** | 良性首阴 | 不能天地板、更不能跌停；最好高开低走收阴线，或烂板炸板回落留长上影 | 当日未跌停，且未出现「天地板」形态 |
| **C3** | 承接不破 | 收盘价不能跌破昨日涨停板当天最低点；跌破即强转弱 | 断板日收盘 ≥ 最后一个涨停日的最低价；最好站上 5 日线 |
| **C4** | 换手非出货 | 近期均量 2~3 倍是换手；历史天量 + 分时直线跳水 = 清仓大甩卖 | 量 ÷ 前 10 日均量 ∈ [1.5, 3.5]，且非近一年最大量 |
| **C5** | 板块环境 | 同板块还有低位小弟涨停撑场，说明资金没放弃 | 所属概念涨停 ≥ 3 家，或同行业仍有涨停 |
| **C6** | 次日确认 | 不在断板当天接飞刀，等次日竞价弱转强、回踩不破 | 次日开盘 ≥ 断板收盘×0.97，且次日最低 ≥ 断板最低×0.99 |

### 4.3 三条不碰

- 高位放量跌停断板 —— 不碰
- 断板后第二天直接低开低走、被均价线压着打 —— 不碰
- 板块已经彻底退潮 —— 不碰

### 4.4 操作纪律

```
断板当天  → 只看不动，放进「反包观察池」
次日竞价  → 符合弱转强，轻仓试错（仓位 ≤ 平时一半）
走错了    → 跌破断板当天最低点，或跌破开盘 30 分钟低点 → 立刻走
走对了    → 加仓
不及预期  → 直接删自选，看都不看
```

### 4.5 监管风险提示（A 股特有）

| 档位 | 触发条件 | 后果 |
|---|---|---|
| 异常波动公告 | 连续 3 日累计偏离 ±20%（ST ±15%） | 公司发公告，无实质影响 |
| 严重异常波动 | 10 日内 4 次异常波动 / 10 日偏离 ≥100% / 30 日偏离 ≥200% | 列入重点监控，大资金难买 |
| 停牌核查 | 严重异常波动后由交易所要求 | 停牌核查，复牌可能补跌 |

**偏离值 = 个股涨幅 − 对应指数涨幅**（大盘下跌时，逆势涨停股的偏离被放大，更容易撞线）。

**C1 的 5 板门槛正踩在监管敏感区下沿**：5 板通常已触发 1~2 次异常波动，10 日内攒满 4 次即进重点监控。

## 五、低吸 vs 打板（两套相反系统）

### 5.1 低吸

| 项目 | 内容 |
|---|---|
| 适用环境 | 震荡市、轮动市、主线极度分歧时的冰点 |
| 做法 | 板块高低切；放量突破、回踩不破再进。宁可晚一步，不赌没发生的事 |
| 死穴 1 | 高位妖股破位后的「假低吸」：连续缩量板后突然天地板砸下来，那是接盘不是低吸 |
| 死穴 2 | 退潮期的阴跌票：缩量阴跌没有底，低吸就是无底洞 |

### 5.2 打板

| 项目 | 内容 |
|---|---|
| 适用环境 | 情绪主升期、发酵期、板块高潮期 |
| 打法 | 昨天烂板/炸板，今天超预期爆量高开、迅速拉升；龙头封单坚决 |
| 死穴 1 | 退潮期打板：总龙头都跌停了，板块亏钱效应炸裂 |
| 死穴 2 | 打加速后的跟风 |

### 5.3 仓位

- **低吸**：轻仓试错，对了加，错了止损
- **打板**：确认后上仓位

### 6.2 涨停放量缩量形态（通达信选股公式）

```
{信号日 = T+2 缩量日，日线周期}
ZT   := REF(C,2) >= ZTPRICE(REF(C,3),0.1);
T1UP := REF(C,1) <  ZTPRICE(REF(C,2),0.1);
T1DN := REF(C,1) >  DTPRICE(REF(C,2),0.1);
NOZB := REF(H,1) <  ZTPRICE(REF(C,2),0.1);
VOLUP:= REF(V,1) >  REF(V,2);
SHRK := V < REF(V,1);
T2DN := C > DTPRICE(REF(C,1),0.1);
MAIN := NOT(CODELIKE('30')) AND NOT(CODELIKE('68'))
        AND NOT(NAMELIKE('ST')) AND NOT(NAMELIKE('*ST'));
XG : ZT AND T1UP AND T1DN AND NOZB AND VOLUP AND SHRK AND T2DN AND MAIN;
```

不支持 `ZTPRICE/DTPRICE` 的版本用百分比替代：

```
ZT   := (REF(C,2)/REF(C,3)-1)*100 >= 9.9;
T1UP := (REF(C,1)/REF(C,2)-1)*100 <  9.9;
T1DN := (REF(C,1)/REF(C,2)-1)*100 > -9.5;
NOZB := REF(H,1) < REF(C,2)*1.1 - 0.011;
T2DN := (C/REF(C,1)-1)*100 > -9.5;
```

## 七、实证提醒（重要）

以下结论来自本项目全市场回测，动手前务必先读：

| 结论 | 数据 |
|---|---|
| 「涨停放量分歧→缩量」形态本身**负期望** | 2025 −0.05%、2026 −0.90%，胜率约 42%（三日版）；四日版 2026 −0.69% |
| 单看个股量价形态不产生 alpha | alpha 在「题材共振 + 辨识度」那一层，形态只能当候选池入口 |
| 首板回调策略组合级不可实盘 | 5 年年化 +9.6%，但回撤 −32%、卡玛 0.30（同期 normal 择时卡玛 1.94） |
| 尾盘收盘价买入系统性亏钱 | 平均支付 −0.44% 隔夜贴水，胜率仅 30% |
| 左尾不能靠止损治理 | 盘中 −3% 止损会误杀大量可修复的票，净效果为负 |
| 信号时刻的行业状态无法预测尾部风险 | 概念/行业 5 日跌幅、昨日跌幅、当日跌幅、有无跌停，四种过滤器全部无效 |

**结论**：战法规则是「筛选与纪律」，不是「收益来源」。真正的期望来自题材周期位置与辨识度，规则负责让你不犯大错。
